# MP3 Player for Android

This repository contains **APK downloads and update metadata only**. Application source code is not published here.

## Install or update

1. Open [the latest release](https://github.com/PiggyChu620/MP3Player-Releases/releases/latest).
2. Under Assets, tap the file ending in **.apk**, then open it and choose **Install** or **Update**.
3. If Android asks, allow your browser to install this APK. Install over the existing app; do not uninstall it.
4. Open MP3 Player. If prompted, tap **Allow updates**, enable **Allow from this source**, then return to the app.

Starting with version 1.4, the app checks GitHub for updates automatically while open.
No GitHub account, Tailscale connection, or running PC is needed to download updates.
Android may ask you to confirm installation. Playback and song downloads postpone installation.
Tap the version number beside the menu to check manually.

Requires Android 7.0 (API 24) or newer. These are debug-signed builds, not Play Store releases.
Updates must retain the original signing certificate. The app checks APK size, SHA-256,
package name, version, compatibility, and signing certificate before installation.

The APK and release metadata are public. Your music library, cookies, credentials, and
playlists are device data and are not uploaded by this publishing process.
